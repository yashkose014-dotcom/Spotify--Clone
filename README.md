
# 🎵 Spotify Clone

A modern and responsive **Spotify Clone** built to recreate the core music-streaming experience of Spotify. This project includes a clean music player interface, playlists, albums, songs, and playback controls.

## ✨ Features

- 🎧 Modern Spotify-inspired user interface
- ▶️ Play and pause songs
- ⏭️ Next and previous song controls
- 🔊 Volume control
- 📀 Albums and playlists
- 🎵 Browse songs and artists
- 🔍 Search functionality
- ❤️ Like/favorite songs
- 📱 Fully responsive design
- 🎨 Dark-themed UI
- ⚡ Fast and smooth user experience

## ⚙️ Installation & Setup

### 1. Open the project folder

```bash
cd spotify-clone
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Open in your browser

```text
http://localhost:5173
```

---

## 📦 Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
